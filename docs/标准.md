# jin10x 标准文档

**crate**：`jin10x` v0.1.2 · **source_id**：`jin10` · **角色**：金十数据源事实层 ·
**状态**：`production_decision = NO-GO`（无采集授权，non-package-stable）

权威输入：`specs/adapter/jin10.md`（采集范围权威）。
本文只登记本库**已落地**的能力标准与其边界；未落地者逐条写明。

## 1. 源事实范围

- 本源覆盖清单 §1.1 的 S01–S08 规划接口、§1.2 的四类核心类型与八类 `DataKind`。
- 本库**只做**类型化、离线解析、校验与判定；**不做**采集、存储与再分发。
- 清单未固定的内容（端点、Header、限流数字、统计码全集、其余五类载荷字段）
  一律**不得**在本库出现。
- 授权现状为 `unknown`（无 Owner 签核文件），故一切判定按 fail-closed 进行。

## 2. 信封与数据类别

- [`Jin10Envelope`] 的字段集**逐字**为 `msg_id` / `source` / `kind` / `event_time` /
  `collect_time` / `payload` / `raw_ref`，不增不减。
- [`DataKind`] 恰有八类：`Flash` / `Calendar` / `BigEvent` / `CentralBank` / `Quote` /
  `Treasury` / `Cot` / `EtfInventory`。
- `source` 必须等于 `jin10`；不等者按语义拒绝。
- `collect_time` 早于 `event_time` 属非法（采集不可能先于事件）。
- 载荷类别必须与被声明的 `kind` 一致，不一致按语义拒绝。
- 时间戳只接受 `YYYY-MM-DD` 或 `YYYY-MM-DDTHH:MM:SS`；**不补造** `00:00:00`。

## 3. 规划接口与周期口径

- `INTERFACE_PLANS` 逐条落 S01–S08 的 **标识 + 名称 + 清单「方式」逐字文本 +
  规划周期秒数 + 周期原文**；`InterfaceId::plan` 是按标识查询该表的唯一入口，
  其结果必须与表内条目逐字段一致。
- **周期是规划语义，不是访问合同**：它不表达访问频率、限流配额、SLA 或新鲜度保证。
  本层无网络、无授权，任何周期数字都**不得**被当作可执行参数。
- `declared_transport`（「方式」列逐字文本，如 `WS/SSE + HTTP`）同样只是**规划表述**：
  它**不**代表本层实现任何传输层，也**不**代表本层可发起请求。
- 清单以「每周六」表述者（S07）没有秒级周期，登记为 `None` 而非猜测出来的秒数。

## 4. 离线解析与原子失败

- 日历载荷所有可选数值与宏观映射值必须有限；None 保留缺失语义。
- 写入决策对候选或既有事实的非有限值优先返回 `InvalidRejected`，不接受、不视作幂等。

- 解析入口为 `parse_jin10_envelopes(&str)`，**参数只有字符串**：不接受 URL、HTTP 客户端、
  认证信息、环境变量或代理配置。
- 输入形态为单个 JSON 文档：根对象 `_synthetic` + `_note` + `envelopes`。
- **未知字段原子失败**：根对象、信封、载荷三层都拒绝未知字段，整体失败，不做静默忽略。
- **缺必需字段失败**：`msg_id` / `source` / `kind` / `event_time` / `collect_time` / `payload`
  与载荷自身的必需字段缺失时整体失败。
- **重复身份**：同一 `msg_id` 出现两次即整体失败，本层选择**拒绝**而不是去重。
- **只接受显式标注的合成样本**：`_synthetic` 必须为 `true` 且 `_note` 非空；
  未标注或自称真实（`_synthetic: false`）者一律语义拒绝。
- 错误消息**只给形态与位置**（如行列），**不回显**原始正文、取值片段或凭据。
- 清单未固定载荷字段的五类 `DataKind` 返回 `NotApplicable`，**不编造字段**。

## 5. 合成夹具声明

- `tests/fixtures/` 下的样本**全部是合成样本**：由特性 005 自拟，**不是**真实源数据，
  **不构成任何证据**，也不得被表述为「实测」「核验 PASS」或任何证据等级。
- 每个夹具文件自带 `_synthetic: true` 与非空 `_note`，并据此可被解析器接受。
- 夹具的字段名与结构对齐 `specs/adapter/jin10.md` 声明的事实；
  **未**编造清单未提到的端点、字段或统计码。

## 6. 宏观映射与乱序保护

- 仅当消息**显式提供可验证 indicator + 主体 + 业务期间**三项时才可**提议**映射宏观观测。
  三项缺失返回 `Missing`；三项存在但为空/全空白返回 `SemanticallyRejected`。
- 判定顺序为**先跨域后完备性**：跨域拒绝优先于三要素检查。
- 「提议」不是「写入」：本层不写任何存储。
- 本源的**观测形状**值对象是 `Jin10MacroProposal`：源条目标识（`msg_id`）+
  业务期间 + 值 + 源侧单位 + 频率 + 修订标识（恒 `None`）。
  `Jin10Envelope<T>` 是源条目**容器**，不是观测。
- 授权判定复验当前日、生效日与失效日，拒绝公开字段构造的非法日历日期。
- 写入判定复验候选与既有事实的期间及非空 indicator/subject，失败返回 `InvalidRejected`。
- **乱序不得覆盖既有事实**：候选到达序号小于既有事实时返回 `StaleRejected`；
  同身份同值重复到达按幂等处理；到达更晚但取值不同返回 `Conflict`，
  **不**静默覆盖（需要显式修订流程）。
- 本源无官方 vintage 面，修订标识恒为 `None`，**不得**伪造。

## 7. 跨域守卫：Quote 与拍卖/RRP

- **Quote 默认拒绝**：行情类一律不得自动进入宏观观测（`MD-1-R04` 精神），
  即使三要素齐备也返回 `RoutedElsewhere`。
- **拍卖 / 逆回购与 `treasuryx` 重叠**：写入主权登记为 **`pending`（未决）**，
  双方**均不得**主张权威写入；本库**保持拒绝**（`WriteAuthorityDenied`），
  并把 `pending` 如实登记（`PENDING_WRITE_SOVEREIGNTY_NOTE`），**不得**自行裁定归谁。
- 写入主权查询是**只读结论**，不改变任何授权状态，也不改变名册登记值。

## 8. 授权判定（fail-closed）

- `authorize` 在以下任一情形一律返回 `Denied`：证据缺失、覆盖范围不明、签署者不明、
  未获 Owner 签核、尚未生效、已过期。**不得**默认放行。
- 判定是**只读**结论：**不改变**名册的登记值，也**不**表示本库生产就绪。
- 本源当前**无**签核文件，故正常调用路径上的结果是 `Denied`；
  `Authorized` 仅在证据形状完整且落在有效期内时出现。
- `ensure_authorized` 把 `Denied` 映射为分类为 `AuthorizationDenied` 的类型化错误。

## 9. publication 与 PIT 资格

- `publication_semantics()` **恒为** `(Date, Inferred, NotEligible)`。
- `is_formal_pit_eligible()` 恒为 `false`（对应清单的 `is_formal_pit_eligible() == false` 口径）。
- **不得**补造 `00:00 UTC` / `21:00 UTC` 之类时刻把 `Date` 伪装成 `Instant`。
- 日后若接入官方 vintage 或经签批的发布日历，须先改清单与契约，**禁止静默升格**。

## 10. 依赖与零网络边界

- 依赖仅 `thiserror` / `serde` / `serde_json`；**禁止**任何 HTTP 客户端、异步运行时、
  `chrono` / `time` / `rand`，也**禁止**依赖任何其它 `bytechainx/*` crate。
- 源码中**没有**任何端点字面量、URL、凭据读取或代理配置；`http://` 与 `https://`
  只可出现在元数据与文档的仓库链接里，不可出现在 `src/` 下的**任何** `.rs` 文件
  （含其内联测试）。需要 URL 字面量的负向用例一律放在 `tests/` 下，
  **不得**用「拆开 scheme 在运行期拼装」之类写法规避扫描 —— 那会让本条的
  可执行断言失去意义。
- 值对象**不实现**派生指标（净流动性、利差、Credit Impulse、z-score 等）。
  `CalendarEvent::surprise_z` 只是**源侧字段**的承载：源未给出即 `None`，本层不计算。
- 单位保留源侧口径（`Jin10Unit`），**不换算**；换算归下游 Normalize。
